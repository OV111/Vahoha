# Pitch: Vahoha

Claims match the code and `docs/product/EXAM_INTEGRITY.md`: "defended", never "verified" or "hard to fake". No traction is claimed because there is none yet.

## One-liner
Vahoha is a learning platform for developers who want proof, not a completion badge: you pass tests to move forward, then defend your own project and get a public record of it.

## 30-second pitch
Developers learn from videos, roadmaps and AI, and nothing checks whether they understood. Then AI writes passing code for anyone, so "it works" no longer shows skill. On Vahoha you move through a roadmap by passing graded tests, an AI mentor that knows your weak spots helps you fix them, and you finish by building a capstone and defending it under a timer. The result is a public page of what you built and could explain. It's built and about to be tested with its first real learners.

## Problem
- Self-taught and junior developers can't show they are ready for mid-level work. Certificates and finished courses prove completion only.
- Mid-level skills (design, debugging, defending decisions, working in a team) are the ones nobody checks.
- AI makes written proof and passing code cheap, so employers trust them less.

## Solution
- Layers unlock by passing a graded test, and failures name the weak topics.
- A mentor that reads your test history and progress.
- Coding challenges and labs, then a capstone with AI review and a timed defense of your own code.
- Build Teams: merged PRs and defenses become a public evidence page.

## Why now
- AI mentors are affordable for a solo product (about $1-2 per heavy user, estimate).
- AI-written code raises the value of "can you explain it".
- Competitors teach well (roadmap.sh, Boot.dev, Codecademy) but none found in October 2026 publishes a learner's defended work (`competitor-matrix.md`).
- Honest caveat: this lead is months, not years, and copyable.

## Not yet claimable
- Users, revenue, hires or employer demand: none. TODO: confirm after interviews.
- Test integrity: multiple choice can be answered with an LLM, so tests are practice; the defense is the stronger signal.
